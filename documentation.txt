1. DESCRIPTION DU PROJET
=========================
Application web React (formulaire d'inscription) avec backend Python (FastAPI),
base de données MySQL, et interface Adminer. Le tout est déployé automatiquement
via une pipeline CI/CD GitHub Actions sur deux instances AWS EC2 distinctes.

3. DÉTAIL DES COMPOSANTS
=========================

3.1 Registre Docker Privé (EC2 #1)
------------------------------------
- Provisionné avec : Terraform (registry/main.tf)
- Configuré avec   : Ansible  (registry/playbook.yml)
- Conteneurs       : registry:2 + joxit/docker-registry-ui
- Authentification  : htpasswd (bcrypt) — admin / admin123
- Ports ouverts     : 22 (SSH), 80 (UI), 5000 (Docker API)

3.2 Application (EC2 #2)
--------------------------
- Provisionné avec : Terraform (deploy/terraform/main.tf) — depuis la pipeline
- Configuré avec   : Ansible  (deploy/ansible/playbook.yml) — depuis la pipeline
- Images Docker    : tirées du registre privé
- Conteneurs       :
    • bdd-projet  : MySQL avec migrations SQL
    • server-api  : Backend FastAPI (Python)
    • frontend    : React (Vite dev server)
    • adminer     : Interface admin BDD
- Ports ouverts    : 22, 80, 3000, 8000, 8080

4. PIPELINE CI/CD (deploy.yml)
===============================

Déclenchement : Manuel (workflow_dispatch) depuis l'onglet Actions de GitHub.

Étapes :
  1. Build des 3 images Docker (frontend, backend, database)
  2. Push sur le registre privé AWS (35.180.174.97:5000)
  3. Terraform init + apply → création de l'EC2 applicative
  4. Récupération de l'IP et de la clé SSH (outputs Terraform)
  5. Génération dynamique de l'inventaire Ansible (inventory.ini)
  6. Exécution du playbook Ansible :
     - Installation Docker
     - Configuration du registre insecure
     - docker login + docker compose pull + up
  7. Validation post-déploiement : curl sur Frontend et Backend

5. SÉCURITÉ
=============

Tous les secrets sont stockés dans GitHub Secrets :
  - AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY : credentials AWS
  - REGISTRY_IP / REGISTRY_USER / REGISTRY_PASSWORD : registre Docker
  - MYSQL_ROOT_PASSWORD : mot de passe de la base de données

Aucun identifiant n'est codé en dur dans le code source.
Le fichier .env.sample documente les variables nécessaires.

7. INSTRUCTIONS DE REPRODUCTION
=================================

  1. Forker/cloner le repository
  2. Configurer les GitHub Secrets (voir .env.sample)
  3. Aller dans Actions > "Deploy Full Stack Application"
  4. Cliquer sur "Run workflow"
  5. Attendre la fin du workflow (~5-10 minutes)
  6. Récupérer l'IP de l'application dans les logs du job "validate"
